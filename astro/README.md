# Howdy [Astro](https://astro.build/)

A static Astro site built into `dist/` and served by lighttpd.

## Development

```bash
bin/run
```

Open http://localhost:4321/astro/

## Production

```bash
bin/up
```

Open http://localhost:4321/astro/
